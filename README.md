# Mason Solutions

We publish **[Lightphrase](https://lightphrase.com/)** — a Windows desktop utility that rewrites selected text in place.

Highlight in any app, press `Ctrl+Alt+R`, sweep the wheel, and the selection is replaced where it sits.
